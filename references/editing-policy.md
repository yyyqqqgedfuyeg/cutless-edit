# 通用剪辑判断

规则只描述方法与偏好，不包含单条视频的机构名、原稿或删除时间段。单条原稿在任务 `script.txt`，具体判断在 `decisions.json`；横竖屏默认参数在 `assets/profiles/`。

用户必须提供原稿。已在对话中提供则保存，不再次索取；未提供则询问，不能把阿里转写当作用户原稿。阿里真实ASR是字幕底稿，原稿用于校对，实际口播决定哪些字确实说出。

## Agent决策矩阵

| 类型 | 优先动作 | 必须检查的例外/证据 |
|---|---|---|
| 开录准备、收尾等待 | 删除无效首尾 | 保留开场首音和收尾尾音；ASR漏识别不能直接视为静音 |
| 普通句间气口 | 过长则缩短 | 前句尾音、后句起音及自然呼吸不能被吞掉 |
| 长沉默、忘词、等提示 | 删除或收紧 | 先判断是否是强调、思考或情绪表达，不按时长一刀切 |
| 观点转折、悬念、强调停顿 | 保留表达作用 | 横屏专业风格优先保留；过长可收紧外围空白而不取消停顿 |
| 嗯、呃、无意义填充词 | 确认无语义后删除 | 回答、肯定、犹豫等有表达作用时保留；不机械删除所有“呢、那、的” |
| 卡壳、重复音节、半句话重来 | 保留完整正确的一遍 | 不删掉重录中唯一有效信息；检查重新拼接的主谓、指代及语气 |
| 完整语句重复 | 删除无效重录 | 强调、总结、前后呼应属于有效重复，默认保留 |
| 口误后自我纠正 | 优先正确完整重录 | 原稿与真实发音共同判定；不能用字幕盖掉未修复的错误声音 |
| 口误没有正确替代 | 标记，检查可否删去不损失核心含义 | 影响数字、事实、结论时需指出无法修复；不凭空补音或拼出没说过的意思 |
| 偏离原稿但合理的口语改写 | 保留实际说法 | 不是所有文本差异都属于口误；字幕可以修ASR错字，不重写有效表达 |
| 原稿外的有效补充 | 结合任务目标保留 | 校对记录引用对应原稿上下文，注明口播补充，不伪造原稿引文 |
| 原稿外的无效绕述、录制指令 | 确认无信息价值后删除 | 不能以压时长为由删掉论据、限定条件、风险说明和必要铺垫 |
| 咳嗽、清嗓、碰麦、外部打断 | 位于空白则可删；覆盖人声先尝试修复 | 无法修复时标记；降噪不是把整段含有效内容的人声删掉 |
| 数字、日期、单位、人名、机构名 | 逐项重点复核 | 同音误识别依据原稿纠正；实际说错需处理音频，不能只改字 |
| 否定、条件、范围、程度、转折词 | 重点保护 | 不能把“不是、可能、仅、如果、但”等删掉而改变原意 |
| 画面动作、手势、表情连续性 | 选择自然切点 | 不用花字或缩放掩盖截音；无法同时最优时先保语义和听感 |
| 开场重点、章节切换、结尾行动指令 | 保留完整结构 | 不机械删除前置引导；用户明确精简要求优先 |

## 判断顺序与切口验收

1. 阅读整篇用户原稿，确认段落、观点和术语，再看整段真实转写；不能只检查算法列出的候选。
2. 结合原稿差异、字词时间、前后至少一个完整语义单元判断；算法建议只是线索，agent负责所有删除/保留决定。
3. 对有意义的内容先判断是否需要删除，再选择切点；不得先按能量剪完再解释理由。
4. 切点避开字词、尾辅音、吸气起音及连续动作的重要瞬间，保留保护余量；片段交界使用极短淡入淡出消除爆点，不用长交叉淡化叠加两句人声。
5. 所有切口检查语义、声音起落和画面跳变；首尾检查是否突然开口/截尾，保留停顿检查是否仍有表达作用。不得删除后遗留孤立连接词或丢掉宾语。
6. 默认保持顺序和1倍速度；不通过变速、重排句子或无授权生成补音强行消除错误。
7. 相互冲突时优先用户明确要求、原意和可懂度，再考虑节奏和视觉；有证据不足的片段保留并记录疑点，涉及核心内容才询问具体问题。
8. 逐项写入动作、原片起止时间、理由、原稿/口播依据及替代重录位置。全部确认后锁轨，字幕或风格阶段发现剪辑问题时创建新版本重剪。

## 音频优先

入库后先检查方向、音轨和音画起点。质检指标只能筛查噪音；结合说话、安静区及突发问题位置试听。持续底噪优先尝试6dB轻度降噪，必要时12dB中度；比较齿音、尾音和音色。不要用降噪承诺修复严重削波、缺失声音或所有混响。噪声很重时先降噪再转写；干净人声可直接bypass。

## 停顿与气口

竖屏默认字词间隔超过0.45秒进入候选；普通气口压缩到约0.24秒。横屏专业风格超过0.75秒进入候选，普通气口约0.40秒。分类切换参考0.4/0.65秒；这些是开始复核的默认值，不是机械删除标准。

观点转折、强调、疑问后的等待、情绪表达优先保留。超过1.5秒也可能有表达作用，不能因时长直接删除。思考忘词、等提示、录制准备等空白可以删。保留前句尾音及后句起音，不在词内硬切；删除区间按帧收缩，最多多留约一帧，不向人声侵入。

呼吸不必全部消失。气口缩短优先在字词间空白中间删除，前后各留保护余量。明显吸气声是否保留依据听感，而非“无字词=静音”。没有VAD或试听证据时保守处理。

## 口误、重说与原稿

原稿表明表达意图，实际人声决定成片字幕。合理口语改写、增加的连接词和有效信息不自动删除。辨别重复起句、重录与强调性重复；保留语义完整、事实正确且衔接自然的一次。没有正确重录段的错误不能仅通过字幕改写来掩盖；记录无法无损修复的片段。

相似文本算法只用于定位，不能直接决定删句。`script_comparison.json` 不包含可信的逐字符音频时间，手工删除时间应回查 `asr/words.json` 和音频。机器词可能多字，不允许均分得到虚构字时间。

为所有候选写出动作和理由。新增手工删段应覆盖完整错误起句且避开相邻有效词。复核关键数字、否定词、转折、机构名称；避免因删除“不是”等词改变意思。

## 轨道锁定

先精剪后字幕。切口与保留停顿全部确认后锁定：素材、音轨、原稿、原始转写、预览字幕、决策及片段时间轴参与校验。锁定后修改字幕位置、字号和文字不会改轨道；重新剪辑必须新建任务版本。

锁定前的确认默认由agent自行完成。仅在确需用户判断或当前工具无法确认影响语义的问题时，提出具体问题；不要常规要求用户批准每个切口。无法听音时如实注明，不把自动检测或转写当成听感验收。

## 字幕与风格

正式字幕按原始字词通过锁定时间映射生成，之后才做文字校对。最多两行，连贯句优先同一块内换行；统一底部锚点、字体与字号。人名、机构、数字单位、否定词组列入任务术语；固定位置不合适时全片整体调整。

每条字幕必须有对照原稿的校对记录，即使完全无需修改也要确认。先生成draft；agent通过 `review_subtitles.py` 提交文字、起止时间、原稿实际引文、对齐确认和理由后才能成为final。允许确认原稿一致、纠正ASR错误、保留合理口语改写或补充；无法解决的冲突不能标记为通过。代码只核查记录是否完整、一致及过期，语义和听感仍由agent真实复核，禁止编造校对证据。

基础字幕与重点词分层，基础字幕不因强调变大跳动。重点词和画面缩放共用时间段。每个语义重点最多一种文字效果和一次缓慢推进；不为每个名词加特效。横屏效果更克制；竖屏可略明显。发现人物裁切、皮肤颜色异常或文字挡脸，调整效果而不是改变锁定切点。

调色默认按画幅选择轻度预设，需要看实际画面；肤色或曝光不合适时关闭，不将预设视作自动白平衡修复。BGM可选内置原创合成循环或来源明确的外部文件，音量低于人声并自动避让；无合适素材可以不加。音效仅在选定重点事件添加，不逐句播放。字幕弹跳采用固定锚点缩放回弹，横屏建议4%、竖屏8%，优先用于少量重点；避免花字、缩放和声音同时密集争抢注意力。
